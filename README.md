# Positivus Landing Page

A responsive landing page for a digital marketing agency, recreated from the Positivus Figma design using pure HTML and CSS.

## Features

- Responsive desktop and mobile layout
- Figma-inspired UI
- HTML5 semantic structure
- Pure CSS styling
- Service cards
- Case studies
- Working process section
- Team section
- Testimonials
- Contact form
- Responsive footer

## Technologies Used

- HTML5
- CSS3
